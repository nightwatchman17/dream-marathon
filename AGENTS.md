# AGENTS.md - Dream Marathon Spirit

## Project Overview
Dream Marathon Spirit is a static frontend website for the Dream Marathon community. The site promotes Dream Marathon 1.0 (coming soon) and drives users to register via a Google Form. No backend or database is used.

## Main Technologies
- **HTML5** - Semantic structure in `index.html`
- **CSS3** - Styling split across `index.html` (embedded styles) and `style.css` (dark theme overrides)
- **Vanilla JavaScript** - Mobile navigation toggle in `index.html` (lines ~481-499)
- **Google Fonts** - DM Sans and Manrope (loaded from Google Fonts)

## Folder Structure
```
Dream Marathon 1.0/
├── .git/                # Git repository
├── gallery/             # Gallery photos + generated photos.js manifest
├── photos/              # Image assets (cover_1.png, cover_2.png, cover_3.png, profile_pic_1.png)
├── scripts/             # build-gallery.mjs (regenerates the gallery manifest)
├── index.html           # Main entry point (contains embedded styles + HTML)
├── gallery.html         # Photo gallery page
├── style.css            # Homepage dark theme overrides and countdown styles
├── gallery.css          # Gallery page styles
├── script.js            # Shared JS: mobile navigation, countdown, gallery rendering
└── README.md            # Project documentation
```

## Entry Points
- **Main page**: `index.html` - Contains the full site structure and embedded CSS; uses `style.css` for the dark theme and `script.js` for behaviour
- **Gallery page**: `gallery.html` - Renders photos listed in `gallery/photos.js`; uses `gallery.css` and `script.js`
- **Styles**: `style.css` loaded after embedded styles (line ~343 in index.html); provides dark theme overrides

## Development
### Running Locally
Open `index.html` directly in a web browser. No build step required.

### Build/Test Commands
No build system, package manager, or tests are configured. There are no `package.json`, build scripts, or test commands.

To refresh the gallery after adding photos, run:
```
node scripts/build-gallery.mjs
```
It rewrites `gallery/photos.js` and keeps existing captions. Captions can also be written in `gallery/captions.txt` using `file name - caption` lines.

### Deployment
- **Live site**: https://nightwatchman17.github.io/Dream-Marathon/
- **GitHub Pages**: Deploys from `main` branch root (`/`). Commits to `main` auto-deploy.

## Project-Specific Notes
- Registration is handled via external Google Form: https://forms.gle/8o8HJQmVtt72QehG7
- Images are stored in `photos/` and referenced relatively (e.g., `./photos/cover_2.png`)
- Gallery photos are stored in `gallery/` and listed in `gallery/photos.js` (generated by `scripts/build-gallery.mjs`). The gallery page shows a sticky thumbnail strip at the top, then each photo large and centered one after another, keeping its natural aspect ratio, with a caption below.
- The countdown on the homepage targets 4 December 2026, 00:00 Bangladesh time (`+06:00`). The date is defined by `RACE_START` in `script.js`.
- The site has responsive design with breakpoints at ~900px, ~680px, and ~380px
- Mobile navigation toggles via JavaScript when screen width < 680px
- Accessibility features include ARIA labels, focus states, and `prefers-reduced-motion` support
