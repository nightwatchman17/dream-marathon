# AGENTS.md - Dream Marathon Spirit

## Project Overview
Dream Marathon Spirit is a static frontend website for the Dream Marathon community. The site promotes Dream Marathon 2026 (coming soon); registration is now closed because all slots are booked. No backend or database is used.

## Main Technologies
- **HTML5** - Semantic structure in `index.html`
- **CSS3** - Styling split across `index.html` (embedded styles), `style.css` (dark theme overrides), and `registration.css` (shared closed-registration dialog)
- **Vanilla JavaScript** - Mobile navigation, countdown, slots, gallery rendering, and the registration-closed dialog in `script.js`
- **Google Fonts** - DM Sans and Manrope (loaded from Google Fonts)

## Folder Structure
```
Dream Marathon 1.0/
├── .git/                # Git repository
├── gallery/             # Gallery photos + generated photos.js manifest
├── photos/              # Image assets (cover_1.png, cover_2.png, cover_3.png, profile_pic_1.png)
├── scripts/             # build-gallery.mjs (regenerates the gallery manifest)
├── index.html           # Main entry point (contains embedded styles + HTML)
├── gallery.html         # Photo gallery page
├── notices.html         # Noticeboard page for marathon announcements
├── style.css            # Homepage dark theme overrides and countdown styles
├── gallery.css          # Gallery page styles
├── notices.css          # Noticeboard page styles
├── registration.css     # Shared registration-closed dialog styles
├── script.js            # Shared JS: mobile navigation, countdown, gallery, closed-registration dialog
└── README.md            # Project documentation
```

## Entry Points
- **Main page**: `index.html` - Contains the full site structure and embedded CSS; uses `style.css` for the dark theme and `script.js` for behaviour
- **Gallery page**: `gallery.html` - Renders photos listed in `gallery/photos.js`; uses `gallery.css` and `script.js`
- **Noticeboard page**: `notices.html` - Announcements and updates; notices are edited directly in the `<article class="notice">` blocks; uses `notices.css` and `script.js`
- **Styles**: `style.css` loaded after embedded styles (line ~343 in index.html); provides dark theme overrides. `registration.css` is shared by all pages for the registration-closed dialog.

## Development
### Running Locally
Open `index.html` directly in a web browser. No build step required.

### Build/Test Commands
No build system, package manager, or tests are configured. There are no `package.json`, build scripts, or test commands.

To refresh the gallery after adding photos, run:
```
node scripts/build-gallery.mjs
```
It rewrites `gallery/photos.js` and keeps existing captions. Captions can also be written in `gallery/captions.txt` using `file name - caption` lines.

### Deployment
- **Live site**: https://nightwatchman17.github.io/dream-marathon/
- **GitHub Pages**: Deploys from `main` branch root (`/`). Commits to `main` auto-deploy.

## Project-Specific Notes
- Registration is closed — all slots are booked. There is no Google Form link left in the site; every registration button carries `data-registration-closed` and opens a shared dialog from `script.js` (styled in `registration.css`)
- Images are stored in `photos/` and referenced relatively (e.g., `./photos/cover_2.png`)
- Gallery photos are stored in `gallery/` and listed in `gallery/photos.js` (generated by `scripts/build-gallery.mjs`). The gallery page shows a sticky thumbnail strip at the top, then each photo large and centered one after another, keeping its natural aspect ratio, with a caption below.
- The countdown on the homepage targets 11 December 2026, 00:00 Bangladesh time (`+06:00`). The date is defined by `RACE_START` in `script.js`.
- The homepage slot panel after the countdown reads `data-total` / `data-booked` from `.slots` in `index.html` and calculates slots left, the filled percentage, and the progress bar (currently 200 total, 200 booked, 0 left, 100% filled)
- The left column of the `.slots` section in `index.html` shows a prominent red highlighted closed-status callout (`role="status"`) — "Registration closed / All slots are booked."; no deadline text is shown
- The header Facebook button on all three pages links to https://web.facebook.com/profile.php?id=61596623797076
- The site has responsive design with breakpoints at ~900px, ~680px, and ~380px
- Mobile navigation toggles via JavaScript when screen width < 680px
- Accessibility features include ARIA labels, focus states, and `prefers-reduced-motion` support
